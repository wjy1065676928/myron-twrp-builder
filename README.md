# myron TWRP builder

基于 [UnicomAndroid/kerneler](https://github.com/UnicomAndroid/kerneler) 的 TWRP 构建流程，
为 Redmi K90 Pro Max (myron / SM8850) 编译 [TWRP-Test](https://github.com/TWRP-Test) 的
`twrp-16.0`（LVGL 新 UI）recovery。

设备树：[MissMyTime/twrp_device_sm8850](https://github.com/MissMyTime/twrp_device_sm8850)

在 Actions 里手动运行 `Build TWRPs` 即可，产物为该 run 的 artifact `recovery-myron-<date>`。
